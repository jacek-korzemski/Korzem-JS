Lekcja 02

Własny tag, atrybuty, HTML w środku.

Korzem.define("karta") rejestruje <k-karta>. Prefiks k- dopisywany jest sam, gdy go nie podasz — przeglądarka i tak wymaga myślnika w nazwie.

Co trafia do render

Atrybuty z listy attributes lądują w props. Myślnik w nazwie zamienia się na camelCase. To, co było między tagami, wraca jako innerHTML — oryginał sprzed renderu, nie wynik poprzedniego rysowania.

Funkcja dostaje też data (jeśli atrybut data={klucz} wskazuje store), store i sam element jako this.

Korzem.define("karta", {
  attributes: ["tytul", "autor"],
  render({ props, innerHTML }) {
    var slot = (innerHTML || "").trim();
    return Korzem.html`
      <article class="karta">
        <p class="karta-autor">${Korzem.escape(props.autor)}</p>
        <h2>${Korzem.escape(props.tytul)}</h2>
        <div class="karta-tresc">${slot}</div>
      </article>
    `;
  }
});

document.querySelectorAll("k-karta").forEach(function (el) {
  if (typeof el.refresh === "function") el.refresh();
});

Elementy k-* przy difie porównują outerHTML. Po renderze środek jest inny niż w pliku, więc przy powrocie na stronę tag jest wstawiany od nowa. Dlatego belka tej witryny jest zwykłym HTML-em. refresh na końcu skryptu poprawia tagi, które przy wejściu z innej lekcji podłączyły się wcześniejszą definicją.

Dwie karty, jedna definicja

Zwykły HTML w środku: slot, nie osobny szablon. Definicja jest jedna. Różnią się atrybuty.
