Lesson 03

The constant and the attribute share a name.

Korzem.data puts the response in the store and returns it. Braces in an attribute are not a template — they name a store key. The component subscribes and re-renders when that key changes. Reactivity without a Virtual DOM.

This lesson’s script

const posts = await Korzem.data("posty", "/dane/posty.json");
page.transient("posty");

page.subscribe("posty", function (value) {
  var count = document.getElementById("count");
  count.textContent = Array.isArray(value) ? String(value.length) : "0";
});

page.on(document.getElementById("append"), "click", function () {
  var list = store.get("posty").slice();
  list.push({
    tytul: "Added in this session",
    data: "now",
    tresc: "A new array, because the store compares by reference."
  });
  store.set("posty", list);
});

slice matters: store.set compares by reference. page.transient("posty") deletes the key on leave. Component: komponenty/lista-postow.js.
