Lekcja 04

Src, import, albo plik który sam importuje.

Tag text/korzem może mieć src. Jeśli w kodzie jest instrukcja import albo export, korzem puszcza go jako moduł. import() jako wywołanie zostaje zwykłą funkcją i modułu nie włącza.

1. Plik z src

Kolejność jest po kolei: ten plik kończy się, zanim ruszy następny skrypt. Ścieżki ./, ../ i /plik są przepisywane na pełny adres — blob, w którym leci moduł, nie ma katalogu ani originu strony.

<script type="text/korzem" src="/komponenty/index.js"></script>
import { defineKarta } from "./karta.js";
import { defineListaPostow } from "./lista-postow.js";

defineKarta(Korzem);
defineListaPostow(Korzem);
window.__korzemZrodloKomponentow = "komponenty/index.js";

2. Import w tagu

<script type="text/korzem">
  import { powitanie } from "/komponenty/format.js";
  document.getElementById("powitanie").textContent = powitanie("inline");
</script>

3. Plik, który importuje

strony/importy.js bierze formatDate z ../komponenty/format.js. page.onLeave działa tak samo jak w skrypcie wpisanym w HTML.

import { formatDate } from "../komponenty/format.js";

var el = document.getElementById("data-pliku");
if (el) {
  el.textContent = formatDate("2026-09-24");
}

page.onLeave(function () {
  window.__korzemOstatnieWyjscie = "Importy: skrypt z pliku dostał onLeave.";
});
