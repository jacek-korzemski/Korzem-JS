Lekcja 01

Klik nie ładuje dokumentu od zera.

Zostaje ten sam dokument i ten sam korzem.js. Treść, która się różni, najpierw znika, potem wraca już nowa. W menu klasa active schodzi z jednego linku i narasta na drugim — podkreślenie CSS, nie cała belka. To jest SPA zbudowane na pełnych stronach HTML, nie na pustej skorupie.

Co robi router

  1. Klik w <a href> tej samej domeny. Pomijane są #, mailto:, tel:, download, target="_blank" i data-korzem-ignore.
  2. fetch z nagłówkiem X-Korzem: 1. Odpowiedź inna niż text/html oddaje nawigację przeglądarce.
  3. Parser składa drugi dokument. Tytuł i meta wchodzą do głowy. Skrypty text/korzem są wyjmowane razem z atrybutem src.
  4. Diff idzie po dzieciach, indeks przy indeksie: tekst, atrybuty, dodanie, usunięcie, zamiana tagu. Stare skrypty korzem są usuwane wcześniej, żeby nie odpaliły się drugi raz.
  5. Klik od razu zanika bloki w main (300 ms, belka zostaje). Fetch idzie równolegle — najechanie albo focus linku może mieć HTML już w cache. Potem pushState i skrypty strony.
  6. data-korzem-fade na boxie zanika całą ramkę, nawet gdy ten sam węzeł zostaje, a skacze tylko jego wysokość.
Nowy węzeł

Tego akapitu nie ma na stronie startowej. Przyszedł z HTML-em tej lekcji, więc animacja wejścia dotyczy jego, nie całego body.

Obiekt page

Każdy skrypt text/korzem dostaje page, Korzem i store. Przy wyjściu kontekst gasi timery, listenery i fetche — bez wycieków między lekcjami.

  • page.on, page.interval, page.timeout
  • page.fetch — ten sam AbortController co reszta kontekstu
  • page.subscribe, page.transient, page.onLeave

Skrypt tej lekcji

var zmiany = document.getElementById("zmiany");
page.on(document, "korzem:navigate:end", function (e) {
  var list = e.detail.changes || [];
  var counts = {};
  list.forEach(function (c) {
    counts[c.type] = (counts[c.type] || 0) + 1;
  });
  var parts = Object.keys(counts).map(function (k) {
    return k + ": " + counts[k];
  });
  zmiany.textContent = list.length
    ? "To przejście dotknęło " + list.length + " węzłów (" + parts.join(", ") + ")."
    : "Żaden węzeł się nie różnił.";
});

page.on(document.getElementById("idz-dane"), "click", function () {
  Korzem.navigate("/pl/dane.html");
});
