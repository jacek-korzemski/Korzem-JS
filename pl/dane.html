Lekcja 03

Stała i atrybut mają tę samą nazwę.

Korzem.data wkłada odpowiedź do stora i zwraca ją do stałej. Klamry w atrybucie to nie szablon — to nazwa klucza. Komponent subskrybuje store i rysuje się ponownie, gdy klucz się zmieni. Reaktywność bez Virtual DOM.

Skrypt tej lekcji

const posty = await Korzem.data("posty", "/dane/posty.json");
page.transient("posty");

page.subscribe("posty", function (value) {
  var ile = document.getElementById("ile");
  ile.textContent = Array.isArray(value) ? String(value.length) : "0";
});

page.on(document.getElementById("dopisz"), "click", function () {
  var lista = store.get("posty").slice();
  lista.push({
    tytul: "Dopisane w sesji",
    data: "teraz",
    tresc: "Nowa tablica, bo store porównuje referencję."
  });
  store.set("posty", lista);
});

slice jest potrzebny: store.set porównuje referencję. page.transient("posty") kasuje klucz przy wyjściu. Komponent: komponenty/lista-postow.js.
