Lekcja 02

Własny tag, atrybuty, HTML w środku.

Korzem.define("karta") rejestruje <k-karta>. Prefiks k- dopisywany jest sam — przeglądarka wymaga myślnika w nazwie custom elementu. Żadnego Reacta, żadnego Vue: render to string HTML.

Co trafia do render

Atrybuty z listy attributes lądują w props. Myślnik w nazwie zamienia się na camelCase. To, co było między tagami, wraca jako innerHTML — oryginał sprzed renderu.

Funkcja dostaje też data (gdy data={klucz} wskazuje store), store i element jako this.

Korzem.define("karta", {
  attributes: ["tytul", "autor"],
  render({ props, innerHTML }) {
    var slot = (innerHTML || "").trim();
    return Korzem.html`
      <article class="karta">
        <p class="karta-autor">${Korzem.escape(props.autor)}</p>
        <h2>${Korzem.escape(props.tytul)}</h2>
        <div class="karta-tresc">${slot}</div>
      </article>
    `;
  }
});

Elementy k-* przy difie porównują outerHTML. Belka witryny jest zwykłym HTML-em, żeby diff nie wymieniał jej przy każdym przejściu.

Dwie karty, jedna definicja

Zwykły HTML w środku: slot, nie osobny szablon. Definicja jest jedna. Różnią się atrybuty.
