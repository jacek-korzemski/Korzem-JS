Lekcja 05

Ten sam motyw, inne permalinki.

Korzem nie jest wtyczką do fragmentów AJAX. WordPress dalej oddaje cały dokument pod każdym adresem — to samo widzi Google. Biblioteka pobiera ten HTML i podmienia tylko to, co się różni. Klasyczny CMS staje się SPA bez utraty SEO.

Skrypt w motywie

Ładuj korzem.js na każdej stronie. Piąty argument true = stopka.

add_action('wp_enqueue_scripts', function () {
    wp_enqueue_script(
        'korzem',
        get_stylesheet_directory_uri() . '/korzem.js',
        array(),
        null,
        true
    );
});

Włącz ładne permalinki. Adres ma być ścieżką (/o-mnie/), nie samym ?p=.

Jeden header na wszystkie szablony

header.php i footer.php wspólne. W <main> zmienia się treść. Jeśli belka ma inny HTML na single niż na liście, diff wymieni całą belkę.

Klasa active

Na <a> dopisz active. Diff podmienia klasę; CSS zanika podkreślenie przez var(--korzem-duration).

add_filter('nav_menu_link_attributes', function ($atts, $item) {
    $classes = is_array($item->classes) ? $item->classes : array();
    if (in_array('current-menu-item', $classes, true)) {
        $atts['class'] = isset($atts['class'])
            ? $atts['class'] . ' active'
            : 'active';
        $atts['aria-current'] = 'page';
    }
    $url = $item->url;
    $outside = strpos($url, home_url()) !== 0;
    $system = strpos($url, '/wp-admin') !== false
        || strpos($url, 'wp-login.php') !== false
        || strpos($url, 'action=logout') !== false;
    if ($outside || $system) {
        $atts['data-korzem-ignore'] = '';
    }
    return $atts;
}, 10, 2);

Cały dokument, nie kawałek

Odpowiedź na X-Korzem: 1 ma być tym samym HTML-em co zwykłe wejście. Fragment z pętli wpisów zniszczy diff albo zostanie odrzucony.

Skrypty i formularze

Logika podstrony: type="text/korzem". Admin bar: data-korzem-ignore po każdym diffie. Szukajka może wołać Korzem.navigate("/?s=" + encodeURIComponent(q)).

Co zostaje, co znika

  • Zostaje: logo, menu, godzina sesji, stopka o tym samym zdaniu.
  • Znika i wraca: nagłówek lekcji, akapity, ten panel.
  • Ignoruj: wp-admin, logowanie, wylogowanie, linki poza domeną.

Motyw ma oddać pełną stronę także przy X-Korzem. Inaczej pierwsze kliknięcie wyleci ze stanu SPA.
