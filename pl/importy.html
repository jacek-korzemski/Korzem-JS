Lekcja 04

Src, import, albo plik który sam importuje.

Tag text/korzem może mieć src. Jeśli w kodzie jest instrukcja import albo export, korzem puszcza go jako moduł. Bez Vite, bez webpacka — ścieżki ./, ../ i /plik są przepisywane na pełny adres.

1. Plik z src

Kolejność jest sekwencyjna. Blob modułu nie ma katalogu strony, więc korzem rozwiąże ścieżki względne.

<script type="text/korzem" src="/komponenty/index.js"></script>

2. Import w tagu

<script type="text/korzem">
  import { powitanie } from "/komponenty/format.js";
  document.getElementById("powitanie").textContent = powitanie("inline");
</script>

3. Plik, który importuje

strony/importy.js bierze formatDate z ../komponenty/format.js. page.onLeave działa tak samo jak w skrypcie wpisanym w HTML.
