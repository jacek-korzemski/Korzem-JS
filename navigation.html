Lesson 01

A click does not reload the document from scratch.

You keep the same document and the same korzem.js. Content that differs fades out, then comes back already updated. In the menu, active moves from one link to another — a CSS underline, not a full header swap. That is an SPA built on real HTML pages, not an empty shell.

What the router does

  1. Click a same-origin <a href>. Skipped: #, mailto:, tel:, download, target="_blank", and data-korzem-ignore.
  2. fetch with header X-Korzem: 1. Non-text/html responses fall back to the browser.
  3. Parser builds a second document. Title and meta update the head. text/korzem scripts (with src) are extracted before the diff.
  4. Diff walks children index-by-index: text, attributes, add, remove, tag replace. Old Korzem scripts are torn down first.
  5. Click immediately fades blocks in main (300 ms; bar stays). Fetch runs in parallel — hover or focus may already have HTML cached. Then pushState and page scripts.
  6. data-korzem-fade fades a whole box even when the same node stays and only its height jumps.

The page object

Every text/korzem script gets page, Korzem, and store. On leave, the context clears timers, listeners, and fetches — no leaks between lessons.

  • page.on, page.interval, page.timeout
  • page.fetch — same AbortController as the rest of the context
  • page.subscribe, page.transient, page.onLeave
