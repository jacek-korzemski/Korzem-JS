Lekcja 05

Ten sam motyw, inne permalinki.

Korzem nie jest wtyczką do fragmentów. WordPress dalej oddaje cały dokument pod każdym adresem. Biblioteka pobiera ten HTML i podmienia tylko to, co się różni od strony już otwartej.

Skrypt w motywie

Plik korzem.js leży w motywie. Ładuj go na każdej stronie. Piąty argument true znaczy stopkę: plik nie blokuje parsera, init idzie na następnej klatce, gdy body już jest.

add_action('wp_enqueue_scripts', function () {
    wp_enqueue_script(
        'korzem',
        get_stylesheet_directory_uri() . '/korzem.js',
        array(),
        null,
        true
    );
});

Włącz ładne permalinki. Adres strony ma być ścieżką (/o-mnie/), nie samym ?p=, jeśli menu ma prowadzić do osobnych dokumentów.

Jeden header na wszystkie szablony

header.php i footer.php są wspólne dla index.php, page.php i single.php. W środku <main> zmienia się treść wpisu. Jeśli belka ma inny HTML na pojedynczym wpisie niż na liście, diff wymieni całą belkę — razem z tym, co miało zostać.

Klasa active

wp_nav_menu stawia current-menu-item na <li>. Na <a> dopisz active, tak jak w menu tej witryny. Diff podmienia klasę od razu, a CSS zanika podkreślenie. Czas bierze var(--korzem-duration), ustawiane przy starcie biblioteki.

add_filter('nav_menu_link_attributes', function ($atts, $item) {
    $classes = is_array($item->classes) ? $item->classes : array();
    if (in_array('current-menu-item', $classes, true)) {
        $atts['class'] = isset($atts['class'])
            ? $atts['class'] . ' active'
            : 'active';
        $atts['aria-current'] = 'page';
    }

    $url = $item->url;
    $outside = strpos($url, home_url()) !== 0;
    $system = strpos($url, '/wp-admin') !== false
        || strpos($url, 'wp-login.php') !== false
        || strpos($url, 'action=logout') !== false;
    if ($outside || $system) {
        $atts['data-korzem-ignore'] = '';
    }
    return $atts;
}, 10, 2);

Cały dokument, nie kawałek

Fetch idzie z nagłówkiem X-Korzem: 1. Odpowiedź ma być tym samym HTML-em co zwykłe wejście, łącznie z <html>, tytułem i stopką. Fragment z samej pętli wpisów korzem odrzuci, bo to nie text/html całej strony — a gdyby nawet sparsował, diff zniszczy dokument.

Skrypty i formularze

Zwykły <script> w treści wpisu przy przejściu się nie wykona. Logika zależna od podstrony to type="text/korzem". Pasek administratora dopisz po każdym diffie, bo atrybutu nie ma w HTML-u z PHP:

<script type="text/korzem">
  document.querySelectorAll("#wpadminbar a").forEach(function (a) {
    a.setAttribute("data-korzem-ignore", "");
  });
</script>

Szukajka i komentarz zostają zwykłym wysłaniem formularza. Żeby szukanie też szło bez przeładowania, przejmij submit i zawołaj Korzem.navigate("/?s=" + encodeURIComponent(q)).

Co zostaje, co znika

Wejście na tę lekcję z innej: belka stoi, podkreślenie active przechodzi na „WordPress”, a boxy z innym tekstem schodzą i wracają.

  • Zostaje: logo, menu, godzina sesji, stopka o tym samym zdaniu.
  • Znika i wraca: nagłówek lekcji, akapity, ten panel.
  • Ignoruj: wp-admin, logowanie, wylogowanie, linki poza domeną.

Motyw ma oddać pełną stronę także wtedy, gdy w żądaniu jest X-Korzem. Inaczej pierwsze kliknięcie w menu wyleci ze stanu aplikacji.
