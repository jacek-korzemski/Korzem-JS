Lesson 05

Same theme, different permalinks.

Korzem is not an AJAX-fragment plugin. WordPress still returns a full document at every URL — the same HTML Google sees. The library fetches that HTML and patches only what changed. A classic CMS becomes an SPA without throwing away SEO.

Script in the theme

Enqueue korzem.js on every page. The fifth argument true means footer.

add_action('wp_enqueue_scripts', function () {
    wp_enqueue_script(
        'korzem',
        get_stylesheet_directory_uri() . '/korzem.js',
        array(),
        null,
        true
    );
});

Enable pretty permalinks. Page URLs should be paths (/about/), not bare ?p=.

One header across templates

Share header.php and footer.php. Inside <main>, post content changes. If the bar’s HTML differs on single vs archive, the diff will replace the whole bar.

The active class

Add active on the <a>. The diff swaps the class; CSS fades the underline with var(--korzem-duration).

add_filter('nav_menu_link_attributes', function ($atts, $item) {
    $classes = is_array($item->classes) ? $item->classes : array();
    if (in_array('current-menu-item', $classes, true)) {
        $atts['class'] = isset($atts['class'])
            ? $atts['class'] . ' active'
            : 'active';
        $atts['aria-current'] = 'page';
    }
    $url = $item->url;
    $outside = strpos($url, home_url()) !== 0;
    $system = strpos($url, '/wp-admin') !== false
        || strpos($url, 'wp-login.php') !== false
        || strpos($url, 'action=logout') !== false;
    if ($outside || $system) {
        $atts['data-korzem-ignore'] = '';
    }
    return $atts;
}, 10, 2);

Full document, not a fragment

Responses to X-Korzem: 1 must be the same HTML as a normal visit. A loop fragment alone will break the diff or be rejected.

Scripts and forms

Page-specific logic uses type="text/korzem". Mark admin-bar links with data-korzem-ignore after each diff. Search can call Korzem.navigate("/?s=" + encodeURIComponent(q)).

What stays, what fades

  • Stays: logo, menu, session time, footer with the same sentence.
  • Fades and returns: lesson heading, paragraphs, this panel.
  • Ignore: wp-admin, login, logout, off-domain links.

The theme must still return a full page when X-Korzem is present. Otherwise the first menu click exits the SPA state.
