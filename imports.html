Lesson 04

Src, an import, or a file that imports.

A text/korzem tag may have src. If the code contains an import or export statement, Korzem runs it as a module. No Vite, no webpack — ./, ../, and /file paths are rewritten to absolute URLs.

1. File with src

Scripts run in order. A module blob has no page directory, so Korzem resolves relative paths for you.

<script type="text/korzem" src="/komponenty/index.js"></script>

2. Import in a tag

<script type="text/korzem">
  import { powitanie } from "/komponenty/format.js";
  document.getElementById("greeting").textContent = powitanie("inline");
</script>

3. A file that imports

strony/importy.js pulls formatDate from ../komponenty/format.js. page.onLeave works the same as in an inline script.
