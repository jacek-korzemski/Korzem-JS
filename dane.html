Lekcja 03

Stała i atrybut mają tę samą nazwę.

Korzem.data wkłada odpowiedź do stora i zwraca ją do stałej. Klamry w atrybucie to nie szablon — to nazwa klucza. Komponent subskrybuje store i rysuje się ponownie, gdy klucz się zmieni.

Skrypt tej lekcji

const posty = await Korzem.data("posty", "/dane/posty.json");
page.transient("posty");

page.subscribe("posty", function (value) {
  var ile = document.getElementById("ile");
  ile.textContent = Array.isArray(value) ? String(value.length) : "0";
});

page.on(document.getElementById("dopisz"), "click", function () {
  var lista = store.get("posty").slice();
  lista.push({
    tytul: "Dopisane w sesji",
    data: "teraz",
    tresc: "Nowa tablica, bo store porównuje referencję. Komponent dostaje zawiadomienie i rysuje się sam."
  });
  store.set("posty", lista);
});

page.onLeave(function () {
  window.__korzemOstatnieWyjscie = "Dane: onLeave, a transient zdjął klucz „posty”.";
});

slice jest potrzebny: store.set porównuje referencję. Ta sama tablica z dopisanym elementem nie budzi subskrybentów.

page.transient("posty") kasuje klucz przy wyjściu. page.onLeave zostawia notatkę, którą widać na lekcji Nawigacja. Komponent jest w komponenty/lista-postow.js — render({ data }) dostaje wartość ze stora, nie string {posty}.
