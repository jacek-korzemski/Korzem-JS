Home

Turn any website into a Single Page App.

korzem.js is one file in the browser. No compiler, no bundler, no framework. A same-origin link click fetches the next page’s full HTML, compares it with the tree already on screen, and updates only the nodes that differ. Google and a cold load still see a complete document — never an empty shell.

Built for SEO, feels like an SPA

Most SPAs ship a blank HTML file and paint content in JavaScript. Search engines then fight hydration and soft 404s. With Korzem you keep real multi-page HTML: every URL returns the full document. Crawlers index it like a classic site; visitors get soft navigation, history, and fades.

What you get

  • SPA navigation. Fetch, DOM diff, pushState — no full reload.
  • Targeted animation. Only changed blocks fade. Menu active moves via CSS.
  • Components. Custom <k-name> tags with attributes and slotted HTML.
  • Data store. Korzem.data plus data={key} on components.
  • WordPress-ready. Same theme, pretty permalinks, footer enqueue.

Drop in (30 seconds)

Put it in <head> with defer, or before </body>. Page logic uses type="text/korzem" so the browser skips it and Korzem runs it with page, Korzem, and store.

From CDN (minified — production)

<script src="https://cdn.jsdelivr.net/gh/jacek-korzemski/Korzem-JS@cdn/korzem.min.js" defer></script>

From CDN (readable — debug / learning)

<script src="https://cdn.jsdelivr.net/gh/jacek-korzemski/Korzem-JS@cdn/korzem.js" defer></script>

Self-hosted + page script

<script src="/korzem.js" defer></script>
<script type="text/korzem">
  const posts = await Korzem.data("posty", "/dane/posty.json");
  page.onLeave(() => console.log("bye"));
</script>
