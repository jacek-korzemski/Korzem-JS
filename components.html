Lesson 02

Your own tag, attributes, HTML inside.

Korzem.define("karta") registers <k-karta>. The k- prefix is added for you — browsers require a hyphen in custom element names. No React, no Vue: render returns an HTML string.

What reaches render

Attributes listed in attributes become props. Hyphens become camelCase. Markup between the tags returns as innerHTML — the original from the source, not the previous render.

You also get data (when data={key} points at the store), store, and the element as this.

Korzem.define("karta", {
  attributes: ["tytul", "autor"],
  render({ props, innerHTML }) {
    var slot = (innerHTML || "").trim();
    return Korzem.html`
      <article class="karta">
        <p class="karta-autor">${Korzem.escape(props.autor)}</p>
        <h2>${Korzem.escape(props.tytul)}</h2>
        <div class="karta-tresc">${slot}</div>
      </article>
    `;
  }
});

k-* elements compare outerHTML during diffs. This site’s header is plain HTML so navigation does not replace the bar every time.

Two cards, one definition

Plain HTML inside: a slot, not a separate template language. One definition. Attributes differ.
